# Phase 1: Foundations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Xcode project and Supabase backend, and ship a working Sign in with Apple → profile onboarding flow — the dependency root every later phase builds on.

**Architecture:** Native SwiftUI iOS app (iOS 17+) backed by Supabase (Postgres + Auth). App state routes between SignIn → Onboarding → MainTabView (placeholder tabs) based on session + profile-completeness. Database schema for the full MVP is created now (all tables from the design spec), with Row-Level Security enabled on every table from the start; only the `users` table gets real policies in this phase — every other table stays locked down (RLS enabled, zero policies = deny-all) until the phase that implements its feature adds policies alongside real usage.

**Tech Stack:** SwiftUI, Swift 6, `@Observable`, `NavigationStack`, supabase-swift (SPM), Supabase (Postgres, Auth, Storage), Supabase CLI + Docker for local dev, pgTAP for RLS tests.

**Reference spec:** `docs/superpowers/specs/2026-08-02-group-closet-design.md`

## Global Constraints

- iOS 17.0 minimum deployment target (spec §4)
- SwiftUI with `NavigationStack` + `@Observable` view models — no Redux/TCA-style architecture (spec §4)
- Supabase: Postgres + Auth + Storage; **no Realtime in v1** (spec §4)
- Sign in with Apple is the only auth method — no email/password (spec §3, §4)
- Row-Level Security is the real privacy boundary, enforced at the database, not just app code (spec §2)
- No formal TDD process for the SwiftUI/UI layer — manual/exploratory QA instead; RLS policy tests at the database level are required and get real automated coverage (spec §6)
- Bundle identifier: `com.aashna.Closet` (actual value from the created Xcode project — capital C; every step below assumes this exact value)
- Project layout: Xcode nested the project one level deeper than originally planned — `Closet/Closet.xcodeproj` and `Closet/Closet/*.swift`, not flat at repo root. This is normal Xcode behavior (it always creates a `<ProductName>/` subfolder at the chosen save location) and every path below reflects it.
- **Never manually edit `Closet/Closet.xcodeproj`/`project.pbxproj` contents.** The project uses Xcode 16+'s synchronized folder groups, so `.swift` files created, edited, or deleted on disk under `Closet/Closet/` are automatically reflected in Xcode — no project-file changes needed for ordinary code work. The few things that genuinely require Xcode's GUI (creating the project, adding SPM packages, enabling capabilities, code signing, deployment target, asset catalogs/app icons) are called out as explicit manual steps in the tasks below; everything else is plain file edits, done in VS Code.
- **Deployment target still needs a manual fix:** the project was created with the default (26.5, the current Xcode SDK version) instead of iOS 17.0. Fix in Xcode: select the `Closet` project → target `Closet` → General → Minimum Deployments → iOS 17.0. Not something to hand-edit in `project.pbxproj`.
- Primary editor is VS Code (via Claude Code) for all Swift code, git, and docs. Xcode is used only for: running the app / SwiftUI Previews, the GUI-only steps above, and later TestFlight builds and App Store assets.

```sql
grant select, insert, update on public.users to authenticated;

create policy "Users can view their own profile"
  on public.users for select
  using (auth.uid() = id);

create policy "Users can insert their own profile"
  on public.users for insert
  with check (auth.uid() = id);

create policy "Users can update their own profile"
  on public.users for update
  using (auth.uid() = id)
  with check (auth.uid() = id);
```

```swift
import Foundation
import Supabase

@Observable
final class AuthViewModel {
    var session: Session?
    var isLoading = true

    private let client = SupabaseService.shared

    init() {
        Task { await loadSession() }
    }

    func loadSession() async {
        session = try? await client.auth.session
        isLoading = false
    }

    func signInWithApple(idToken: String, nonce: String) async throws {
        session = try await client.auth.signInWithIdToken(
            credentials: .init(provider: .apple, idToken: idToken, nonce: nonce)
        )
    }

    func signOut() async throws {
        try await client.auth.signOut()
        session = nil
    }
}
```

- [x] **Step 5: Write the sign-in screen**

Create `Closet/Closet/Auth/SignInView.swift`:

```swift
import SwiftUI
import AuthenticationServices
import CryptoKit

struct SignInView: View {
    let authViewModel: AuthViewModel
    @State private var currentNonce: String?
    @State private var errorMessage: String?

    var body: some View {
        VStack(spacing: 24) {
            Text("Closet")
                .font(.largeTitle.bold())

            SignInWithAppleButton(.signIn) { request in
                let nonce = randomNonceString()
                currentNonce = nonce
                request.requestedScopes = [.fullName]
                request.nonce = sha256(nonce)
            } onCompletion: { result in
                handle(result)
            }
            .signInWithAppleButtonStyle(.black)
            .frame(height: 50)
            .padding(.horizontal, 40)

            if let errorMessage {
                Text(errorMessage)
                    .foregroundStyle(.red)
                    .font(.footnote)
            }
        }
    }

    private func handle(_ result: Result<ASAuthorization, Error>) {
        switch result {
        case .success(let authorization):
            guard
                let credential = authorization.credential as? ASAuthorizationAppleIDCredential,
                let tokenData = credential.identityToken,
                let idToken = String(data: tokenData, encoding: .utf8),
                let nonce = currentNonce
            else {
                errorMessage = "Could not read Apple ID credential"
                return
            }
            Task {
                do {
                    try await authViewModel.signInWithApple(idToken: idToken, nonce: nonce)
                } catch {
                    errorMessage = error.localizedDescription
                }
            }
        case .failure(let error):
            errorMessage = error.localizedDescription
        }
    }

    private func randomNonceString(length: Int = 32) -> String {
        precondition(length > 0)
        let charset: [Character] = Array("0123456789ABCDEFGHIJKLMNOPQRSTUVXYZabcdefghijklmnopqrstuvwxyz-._")
        var result = ""
        var remainingLength = length
        while remainingLength > 0 {
            var random: UInt8 = 0
            _ = SecRandomCopyBytes(kSecRandomDefault, 1, &random)
            if random < charset.count {
                result.append(charset[Int(random)])
                remainingLength -= 1
            }
        }
        return result
    }

    private func sha256(_ input: String) -> String {
        let hashed = SHA256.hash(data: Data(input.utf8))
        return hashed.compactMap { String(format: "%02x", $0) }.joined()
    }
}
```

```swift
import Foundation

@Observable
final class OnboardingViewModel {
    var name: String = ""
    var topSize: String = ""
    var bottomSize: String = ""
    var shoeSize: String = ""
    var isSaving = false
    var errorMessage: String?

    private let client = SupabaseService.shared

    func save(userID: UUID) async -> Bool {
        guard !name.trimmingCharacters(in: .whitespaces).isEmpty else {
            errorMessage = "Name is required"
            return false
        }
        isSaving = true
        defer { isSaving = false }

        var sizes: [String: String] = [:]
        if !topSize.isEmpty { sizes["top"] = topSize }
        if !bottomSize.isEmpty { sizes["bottom"] = bottomSize }
        if !shoeSize.isEmpty { sizes["shoe"] = shoeSize }

        let profile = UserProfile(id: userID, name: name, photoURL: nil, sizes: sizes)

        do {
            try await client.from("users").insert(profile).execute()
            return true
        } catch {
            errorMessage = error.localizedDescription
            return false
        }
    }
}
```

Create `Closet/Closet/RootView.swift`:

```swift
import SwiftUI

struct RootView: View {
    let authViewModel: AuthViewModel
    @State private var hasProfile: Bool?

    var body: some View {
        Group {
            if authViewModel.isLoading {
                ProgressView()
            } else if authViewModel.session == nil {
                SignInView(authViewModel: authViewModel)
            } else if hasProfile == nil {
                ProgressView().task { await checkProfile() }
            } else if hasProfile == true {
                MainTabView()
            } else if let userID = authViewModel.session?.user.id {
                OnboardingView(userID: userID) {
                    hasProfile = true
                }
            }
        }
    }

    private func checkProfile() async {
        guard let userID = authViewModel.session?.user.id else {
            hasProfile = false
            return
        }
        let count = (try? await SupabaseService.shared
            .from("users")
            .select("id", head: true, count: .exact)
            .eq("id", value: userID)
            .execute()
            .count) ?? 0
        hasProfile = count > 0
    }
}
```

```swift
    }
}
```
